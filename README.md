# *Sistema de Mercado em C#* 🛒
Esse sistema tem o objetivo de gerenciar produtos, estoques, vendas e clientes.
Ele simula o funcionamento básico de um mercado, permitindo o controle de estoque, registro de compras e cálculo de valores.

Esse projeto foi desenvolvido por fins didáticos, para desenvolver meu conhecimento na área.


## ⚙ Funcionalidades
- Cadastro de Produtos
- Edição de Produtos
- Gerenciamento de Estoque
- Cálculo do valor total da conta
